# Python Tutoring Examples

Small Python exercises organized by session date, covering data parsing, lookup functions, and simulation.

## Start reading

- [Bird-data lookup](4-27-2025/bird_data.py): named lookup functions and a bundled text dataset.
- [Yahtzee simulation](5-4-2025/yahtzee.py): NumPy dice rolls and outcome counting.
- [Project exercise](5-11-2025/Project_15.py) alongside its [explicit skeleton](5-11-2025/Project_15_Skeleton.py).

## Run one example

With Python and NumPy installed, from the repository root:

```sh
python -m pip install numpy
python 5-4-2025/yahtzee.py
```

The script simulates 5,000 rolls and prints counts and percentages; random results vary. Other exercises may expect their dated directory as the working directory. This collection has no unified test suite or application. Execution was not re-certified in this documentation pass.
